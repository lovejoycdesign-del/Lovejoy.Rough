# LJ Chirombo — Digital Designer Portfolio

Local copy of [Lovejoy.Rough](https://github.com/lovejoycdesign-del/Lovejoy.Rough) so you can edit the site without deploying.

The live Netlify site at [lj-design.netlify.app](https://lj-design.netlify.app/) is not touched by this repo.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:43147](http://localhost:43147). The dev server binds `0.0.0.0` so Cursor preview can reach it.

## Stack

- Next.js (App Router) + React
- TypeScript
- Tailwind CSS
- Google Fonts: Bebas Neue (display), Montserrat (UI/body)

Presentation copy and project list live in `src/data/content.ts`.
