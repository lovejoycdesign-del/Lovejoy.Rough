# LJ Chirombo — Digital Designer Portfolio

Next.js portfolio site for Lovejoy Chirombo (Digital Communication & Media Arts / VCDM491).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + React
- TypeScript
- Tailwind CSS
- Google Fonts: Bebas Neue (display), Montserrat (UI/body)

Presentation copy and project list live in `src/data/content.ts`.
