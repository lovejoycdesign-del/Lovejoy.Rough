# LJ Design Rough

Working book for **Lovejoy Chirombo** — posters, type specimens, still lifes, and identity studies. Achromatic on purpose. Not the polished deck.

The plates reconstruct work from [Behance](https://www.behance.net/lovejoychirombo) as a single sketchbook: crop marks, job tickets, china-marker notes.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43147](http://127.0.0.1:43147). The app listens on port 43147.

- **Index** — all plates, filterable by medium
- **Notes** — how the book is kept
- **Marks** — contact (opens your mail client; no backend)

## Stack

Next.js, TypeScript, Tailwind CSS, shadcn/ui.

## Build

```bash
npm run build
npm start
```
